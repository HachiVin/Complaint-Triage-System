# Complaint Triage System

Live demo of [HachiVin/Complaint-Triage-System](https://github.com/HachiVin/Complaint-Triage-System):
IndoBERT labels every review of a mobile-banking app with its aspect, sentiment and urgency, and the
dashboard shows trends, a critical-complaint queue and a data agent that answers questions with SQL.

The data is the public USH BRImo dataset (CC BY 4.0); urgency labels are silver (not human-verified).
The code is built from the GitHub repository; this Space only holds the Dockerfile.
